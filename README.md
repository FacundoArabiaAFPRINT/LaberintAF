# Laberint AF

Roguelite de terror en vista superior. Diez jugadores despiertan en un laberinto que cambia, cada uno con un cazador propio; matarlo da la llave y la única salida está en el centro.

- Jugar: abrir `index.html` en el navegador (no necesita nada más).
- Probar: `npm install` y `npm test` (Playwright). Las capturas quedan en `.salidas/`.
- Unreal Engine 5: el proyecto está en `unreal/LaberintAF` y la guía en [`unreal/MIGRACION.md`](unreal/MIGRACION.md).

Proyecto de AF PRINT 3D. Repositorio privado.
